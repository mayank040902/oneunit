# Security

Application security guidance for this framework lives in `docs/security.md`.

- JWT, passwords, RBAC, and OAuth: `@oneunit/auth`
- HTTP headers, CORS, cookies, rate limits: `@bootstrap-framework/server`
- Log redaction: `@oneunit/logger` production mode
- Parameterized SQL: `@oneunit/database`
- Kafka TLS/SASL: `@oneunit/kafka`
- WebSocket auth and E2EE: `@bootstrap-framework/realtime`

Report vulnerabilities privately to the maintainer. Do not open a public issue with exploit details.
